# 产品功能清单（标准版 v3.2）

## 审批流模块

- **标准版支持固定三级审批流**：发起人 → 部门主管 → 分管副总。
- 审批节点支持并签、或签两种模式。
- 支持审批超时提醒（默认 24 小时，可在管理后台调整为 12/24/48 小时）。
- **不支持**：自定义审批节点数量、条件分支审批（如"金额大于 10 万走额外审批"）、会签顺序自定义。
- 自定义审批流属于**定制开发范围**，需单独评估工作量与报价。

## 组织架构与权限

- 支持三层组织架构（公司 → 部门 → 小组）。
- 角色权限支持功能级授权，暂不支持字段级权限控制。
- 支持与企业微信、钉钉的通讯录同步（每日定时同步一次，不支持实时同步）。

## 报表与数据

- 内置 12 张标准报表，支持导出 Excel。
- 自定义报表需通过报表设计器配置，标准版包含 5 个自定义报表额度。
- 数据看板支持按日/周/月维度统计。
- **不支持**：自定义 SQL 查询、跨系统数据关联分析。

## 集成能力

- 开放 REST API，提供 60+ 标准接口。
- 支持 Webhook 事件推送（订单状态变更、审批结果等 8 类事件）。
- 单账号 API 调用限额：1000 次/分钟。
- SSO 单点登录支持 OAuth2.0 与 SAML 2.0。

## 移动端

- 提供 iOS / Android 原生 App。
- 移动端支持审批、查看报表、消息通知。
- **移动端不支持**：报表设计器、系统配置、批量数据导入。
