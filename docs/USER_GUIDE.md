# 用户使用指南 (User Guide)

本文档将指导你如何快速配置、上手使用实时会议话术助手。

---

## 1. 首次配置（API Key 与凭据）

启动客户端后，点击左下角【设置】：

### 1.1 语音转写服务 (ASR)
推荐使用 **阿里云通义百炼（Paraformer-Realtime-v2）**：
* 价格极低（约 0.288 元/小时），延迟低，支持热词表定制。开通即赠送测试体验额度。
* [👉 点击前往阿里云百炼控制台获取 API Key](https://bailian.console.aliyun.com/)
* 在设置页填写你的 `ALIYUN_ASR_KEY` 并点击【测试连接】。

### 1.2 建议生成模型 (LLM)
* **首选 Google Gemini** (`gemini-2.5-flash` / `gemini-3.5-flash-lite`)：Google AI Studio 长期提供免费调用额度（Free Tier），首包延迟仅约 2.4s。
  * [👉 点击前往 Google AI Studio 获取免费 API Key](https://aistudio.google.com/apikey)
* **首选 阿里云百炼** (`qwen-turbo` / `qwen-plus`)：每月刷新免费 Token 额度，与 ASR 复用同一个 Key。
  * [👉 点击前往阿里云百炼控制台获取 API Key](https://bailian.console.aliyun.com/)
* **备选 智谱 GLM / DeepSeek**：智谱 `glm-4-flash` 长期免费；DeepSeek 超高性价比。
  * [👉 前往智谱开放平台](https://open.bigmodel.cn/) · [👉 前往 DeepSeek 开放平台](https://platform.deepseek.com/)

## 2. 声纹注册（让系统认识「我」）

为了精确区分会议中哪些话是你说的、哪些话是对方提问，强烈建议在开会前完成声纹录入：

1. 进入【设置】->【声纹管理】或点击【注册我的声纹】。
2. 保持周围环境相对安静，点击【开始录音】并自然朗读屏幕上的提示语句（约 15~30 秒）。
3. 录入完成后点击保存，系统将自动生成本地声纹向量（`.npy` 格式保存在本地）。

## 3. 开会实战与悬浮窗操作

### 3.1 创建新会议
1. 点击【新建会议】，输入会议名称（默认自动填充当前时间）。
2. 关联当前会议相关的**项目知识库文档**（如产品规范、报价规则）。
3. 点击【开始会议】，桌面悬浮窗将自动呼出并置顶在屏幕右上角。

### 3.2 悬浮窗实用技巧
* **悬停锁定 (Hover-Freeze)**：当对方抛出问题且悬浮窗给出建议时，将鼠标移入悬浮窗即可安心阅读，此时不会被后续新发言冲刷。
* **迷你折叠**：点击右上角折叠按钮，悬浮窗将收起为一条高度仅 38px 的胶囊条，完全不挡屏幕。
* **主动生成**：点击悬浮窗顶栏的【魔法棒】图标，可基于最近几轮对话主动刷新建议。

---

## 4. 知识库管理与导入

* 支持拖拽 `.md`, `.txt`, `.docx`, `.pdf` 文件至知识库页面。
* 支持点击【导入文件夹】进行全目录递归检索入库。
* 所有知识库切片与向量索引均保存在本地 SQLite。
