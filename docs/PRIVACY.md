# 隐私与数据安全说明 (Privacy & Security)

实时会议话术助手严格贯彻**隐私第一 (Privacy-First)** 的设计架构：

### 1. 本地存储保证
* **原始音频与录音文件**：完整音频保存在本地目录（`%APPDATA%/meeting-copilot-desktop/`），绝不上传任何云端服务器。
* **声纹特征数据**：本地声纹特征仅在用户本机通过 ONNX 运行时提取，不包含任何个人身份生物特征的云端注册。
* **本地数据库**：会议记录、转写文本、知识库文档全部保存在本机 SQLite 数据库中。

### 2. 外部 API 调用透明性
* 仅在开启会议时，将实时麦克风音频流通过安全 WebSocket 传输给用户**自备凭据**的云厂商 ASR 接口（如阿里云通义百炼）。
* 仅在触发建议生成时，将当轮对话文本与相关知识库片段发送给用户配置的大语言模型接口（如 Qwen、Gemini、DeepSeek）。
* 本软件不设任何中转代理服务器，所有网络请求均为客户端直连云厂商官方 OpenAPI。
