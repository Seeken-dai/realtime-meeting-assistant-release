# 常见问题解答 (FAQ)

### Q1: 开会一小时大概消耗多少费用？
* **语音识别 (ASR)**：使用阿里云 Paraformer-realtime 官方定价约为 0.288 元/小时，一场 1 小时的会议 ASR 成本不足 0.3 元。
* **大模型建议 (LLM)**：根据发言频率，通常单场会议产生 15~30 次智能建议，使用 Qwen-Turbo 或 Gemini Flash 的 Token 成本通常在 0.05~0.1 元。
* 综合单场会议成本在 **0.4 元人民币以内**。

### Q2: 为什么有时会把对方的话识别成“我”？
* 请确保在设置页录入了清晰的个人声纹。
* 在会议室公放或多人混杂场景下，建议佩戴降噪耳机或定向麦克风以获得最佳的声纹信噪比。

### Q3: 悬浮窗在某些全屏游戏或应用上方无法置顶？
* Windows 的部分独占全屏 (Exclusive Fullscreen) 应用会抢占最高层渲染。请将该应用设置为【无边框全屏】或【窗口化】模式，即可正常悬浮置顶。

### Q4: 钉钉/腾讯会议全屏投屏时，参会人员会看到我的悬浮窗吗？
* **不会**。客户端默认开启了 Windows 系统级防捕获保护（`WDA_EXCLUDEFROMCAPTURE`），在钉钉、腾讯会议、Zoom、飞书等全屏投屏或屏幕共享时，悬浮窗对观众完全透明隐形，只有你自己的屏幕可见。你也可以在悬浮窗外观设置中自由开启或关闭此功能。
